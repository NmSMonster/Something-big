# Something Big

Prototype playground. Each project lives in its own folder (or file) and is independent.

| Project | What it is | Where |
| --- | --- | --- |
| **Tiny Trouble** | Roblox multiplayer survival adventure at 2 cm scale (Rojo 7, Luau, Milestone 1 playable foundation) | [`tiny-trouble/`](tiny-trouble/README.md) |
| Cień Miasta | Standalone HTML title-screen prototype | `menu.html` |
| Gwiezdny Czarodziej | Standalone HTML particle experience | `index.html` |

For Tiny Trouble start with [`tiny-trouble/README.md`](tiny-trouble/README.md) and
[`tiny-trouble/docs/SETUP.md`](tiny-trouble/docs/SETUP.md). CI for it runs from
`.github/workflows/tiny-trouble-ci.yml`.
